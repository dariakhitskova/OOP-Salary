# Вариант 19. Расчёт заработной платы (Повышенный уровень)

Консольное приложение на Java 21 для расчёта заработной платы.
Включает полную реализацию **базового** и **повышенного** уровней.

## 📌 Описание модели
Модель построена на двух параллельных иерархиях, объединённых общим интерфейсом `PayrollElement`:
* **Начисления (`Accrual`)** — оклад, премия, ночные, отпускные, больничный.
* **Удержания (`Deduction`)** — НДФЛ, аванс, исполнительный лист.

Все суммы хранятся в копейках (`long`), чтобы избежать ошибок с плавающей точкой.

## 🔥 Реализованный повышенный уровень
В рамках повышенного уровня реализованы следующие механики:

1. **Динамические ставки и лимиты (RatePeriod)**
   Налоговые ставки не захардкожены. Они задаются объектами `RatePeriod` на конкретных интервалах дат (`from`, `to`). Калькулятор сам находит актуальную ставку для рассчитываемого периода.

2. **Перерасчёт задним числом (Backdated Recalculation)**
   Метод `PayrollCalculator.recalculateBackdated()` позволяет пересчитать уже закрытый период (например, если бухгалтер допустил ошибку или задним числом изменилась ставка). Метод возвращает **разницу** между новым и старым расчётом, которую можно вынести отдельной строкой в текущий месяц.

3. **Хранение версий и сравнение листков (Payslip Versioning & Diff)**
   Расчётный листок поддерживает концепцию версий. Метод `Payslip.diff(other)` выполняет построчное сравнение двух версий листка и возвращает список изменений (какая строка увеличилась, уменьшилась или была удалена).

4. **Проверка лимита удержаний**
   Калькулятор автоматически следит, чтобы сумма удержаний (включая налог) не превышала 50% от базы начислений. При превышении выбрасывается проверяемое исключение `DeductionLimitExceededException`.

5. **Принцип открытости-закрытости (OCP)**
   Добавление нового вида начисления (например, `MaternityAllowance`) или удержания не требует изменения класса `PayrollCalculator`. Достаточно создать новый класс-наследник.

## 📂 Структура проекта
* `PayrollElement` — интерфейс (единый контракт).
* `Accrual` / `Deduction` — базовые классы.
* `accruals.*` / `deductions.*` — конкретные виды начислений/удержаний.
* `Employee` — сотрудник (record, ключ — табельный номер).
* `PayrollPeriod` — расчётный месяц.
* `RatePeriod` — ставка на интервале дат.
* `Payslip` / `PayslipLine` — листок и его строки (с поддержкой diff).
* `PayrollCalculator` — расчётчик с поддержкой перерасчёта.
* `Main` — демонстрация всех операций.
